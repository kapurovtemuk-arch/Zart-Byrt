# Zart-Byrt
Zart Byrt (ZB) — Professional Vector Graphics Editor

ZB — современный мобильный графический редактор для Android, созданный для профессионального векторного дизайна, иллюстраций, логотипов и цифрового творчества.

Основные возможности:

- 🎨 Создание и редактирование векторной графики.
- ✏️ Инструмент свободного рисования.
- 📐 Фигуры, линии и кривые Безье.
- 🔤 Добавление и редактирование текста.
- 🎯 Работа с цветами, градиентами и обводками.
- 📚 Система слоёв.
- ↩️ Отмена и повтор действий.
- 🖼️ Импорт изображений.
- 📁 Сохранение и открытие проектов.
- 📤 Экспорт в SVG и PNG.
